# ADR-0001: FastAPI, React и stateless-границы

Статус: accepted.

## Контекст

Нужны удобный UI, явный JSON API, быстрый локальный запуск и возможность дальнейшего развития без CMS/БД в тестовом MVP.

## Решение

Использовать Python 3.12 + FastAPI/Pydantic для backend и React + TypeScript/Vite для frontend. Runtime остаётся stateless. Frontend и backend собираются отдельно, nginx проксирует `/api`.

## Последствия

- API можно тестировать и использовать независимо от UI.
- Появляются два build toolchain, но Docker Compose скрывает их от проверяющего.
- Хранение, аккаунты и фоновые задачи можно добавить позже отдельными компонентами.

## Отклонено

- API-only: неудобно контент-менеджеру.
- Server-rendered UI: меньше инфраструктуры, но слабее граница frontend/API.
- БД «на будущее»: не решает текущую задачу.
