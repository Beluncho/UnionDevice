# ADR-0003: Grounded generation и детерминированные характеристики

Статус: accepted.

## Контекст

Главный риск задания — выдуманные технические значения. Одного prompt-норматива недостаточно.

## Решение

LLM создаёт маркетинговые поля и выбирает ключи характеристик, но не создаёт их значения. Backend подставляет значения прямо из `specs`, проверяет схему, длины, количество запросов и происхождение технических литералов. Допускается одна корректирующая попытка.

## Последствия

- Структурированные характеристики гарантированно совпадают с входом.
- Prose всё ещё требует ручной проверки; технический validator снижает, но не исключает семантические ошибки.
- Непрошедший проверку текст не показывается пользователю.

## Отклонено

- Полностью доверять модели.
- Второй LLM-критик: повышает стоимость и не даёт детерминированной гарантии.
