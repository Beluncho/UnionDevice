# ADR-0004: Без web-enrichment в runtime

Статус: accepted.

## Контекст

При неполной карточке менеджер обычно сверяется с паспортом, производителем или поставщиком. Автоматический поиск потребовал бы оценки доверия, цитат и разрешения конфликтов источников.

## Решение

Runtime использует только присланный JSON. При пробелах он возвращает `needs_clarification` и список отсутствующих групп данных. Ссылки и автоматически найденные сведения в UI/API не показываются.

Доступ к сайту souz-pribor.ru допускается только dev-скрипту подготовки фиксированных примеров; исходные URL не входят в продуктовый контракт.

## Последствия

- Риск скрытого добавления неподтверждённых фактов минимален.
- Менеджер дополняет данные вручную и повторяет генерацию.
- Будущее enrichment-расширение потребует отдельного adapter, provenance/citations, allowlist источников и нового ADR.

## Отклонено

- Ссылка на поисковик из UI: не гарантирует официальный источник.
- Автоматическое заполнение из произвольных страниц: выходит за MVP и ухудшает проверяемость.
