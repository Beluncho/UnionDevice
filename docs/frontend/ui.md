# Frontend UI

## Экран

Одностраничный интерфейс на русском языке:

- Переключатель `Форма / JSON`.
- Название, производитель, описание и динамические строки характеристик.
- Выбор подготовленного примера.
- Кнопка генерации с блокировкой повторной отправки.
- Панель результата с секциями карточки.
- Кнопки копирования JSON и Markdown.

## Синхронизация режимов

- Переход из формы в JSON сериализует текущее нормализованное состояние.
- Возврат из JSON в форму происходит только после успешного явного разбора.
- Ошибка JSON показывается рядом с редактором и не очищает последнюю корректную форму.

## Состояния результата

- `draft_ready`: нейтральная отметка «Черновик готов к проверке».
- `needs_clarification` с проверенным draft: заметное предупреждение и список `missing_fields`; копирование разрешено, Markdown содержит предупреждение.
- `needs_clarification` без draft: если обе LLM-попытки не прошли validator на неполном входе, UI показывает пробелы и предлагает дополнить данные; кнопки копирования результата не выводятся.
- API/сетевая ошибка: локализованное сообщение и возможность повторить запрос без потери ввода.

## Безопасность и доступность

- Не использовать `dangerouslySetInnerHTML` для ответа модели.
- Кнопки и поля имеют подписи, фокус и клавиатурную навигацию.
- Статус запроса объявляется через доступную live-region.
- Ключ и provider config никогда не передаются во frontend bundle.

## Не входит

История карточек, вход пользователя, сложный rich-text редактор, загрузка файлов и ссылки на внешние источники.
