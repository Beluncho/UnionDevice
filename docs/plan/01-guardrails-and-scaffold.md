# Шаг 01: Guardrails и документация

Статус: completed and approved.

## Цель

Зафиксировать требования, архитектуру, контракты, безопасность и последовательность реализации до создания кода.

## Действия

- Создать `AGENTS.md`, `.gitignore`, `.env.example` и карту документации.
- Описать product, backend, frontend, API, LLM, data, operations, quality и security.
- Принять пять ADR.
- Не устанавливать пакеты и не создавать scaffold приложения.

## Критерии выхода

- Нет противоречий между публичным API и проектными документами.
- `.env` исключён из Git и полностью закрыт правилами.
- Все дальнейшие шаги имеют проверяемый результат.
- Пользователь отдельно подтверждает переход к шагу 02.
