# Шаг 02: Окружение и fixtures

Статус: completed.

## Цель

Создать воспроизводимое окружение и три входных примера без ручного копирования технических данных.

## Действия

- Инициализировать Git-репозиторий, если `.git` отсутствует; не создавать удалённый репозиторий и не публиковать код без отдельного запроса пользователя.
- Проверить/создать `.venv`, установить только утверждённые зависимости и зафиксировать requirements.
- Создать backend/frontend и отдельный `catalog-importer` scaffold без бизнес-логики.
- Зафиксировать корневые и компонентные requirements без глобальной установки пакетов.
- Реализовать importer-команды `index`, `enrich` и `prepare-examples` с URL/local XML режимами.
- Сохранить два полных JSON и детерминированный partial-вариант.
- Добавить offline importer tests с минимальными XML/HTML samples.

## Критерии выхода

- `git status` доступен, а секреты, окружения и артефакты исключены правилами `.gitignore`.
- Fixture соответствует входной Pydantic-схеме.
- Повторный запуск даёт семантически тот же JSON.
- В fixtures нет цен, отзывов, картинок и URL.
- Полный JSONL-индекс и cache игнорируются Git.
- Массовый обход товарных страниц отсутствует; enrichment требует offer ID.
- Тесты importer не требуют сети.
