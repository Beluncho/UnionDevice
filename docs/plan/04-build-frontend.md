# Шаг 04: Frontend

Статус: completed; Vitest и production build проверены в Docker.

## Цель

Предоставить контент-менеджеру компактный интерфейс ввода, проверки и копирования черновика.

## Действия

- Реализовать form/JSON режимы и динамические характеристики.
- Добавить загрузку трёх examples через API.
- Показать результат, missing fields, warnings и оба статуса.
- Реализовать копирование JSON/Markdown и обработку ошибок без потери ввода.
- Добавить component tests, TypeScript/ESLint проверки и production build.

## Критерии выхода

- Все сценарии доступны с клавиатуры и адаптируются к мобильной ширине.
- Ответ модели нигде не рендерится как HTML.
- Partial-пример визуально требует уточнения.
- Frontend bundle не содержит provider settings.
