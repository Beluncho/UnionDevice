# Шаг 06: Проверка и сдача

Статус: automatic verification completed; live LLM smoke remains user-only.

## Цель

Подтвердить критерии задания и подготовить репозиторий к просмотру проверяющим.

## Действия

- Запустить backend/frontend tests, lint/type checks, builds и Docker smoke.
- Создать Python API smoke-клиент для трёх fixtures.
- Пользователь запускает live smoke со своим `.env`; результаты сохраняются без секретов.
- Проверить два полных результата и partial-сценарий на технические факты и длины.
- Обновить README: установка, запуск, prompt-решения, ограничения, улучшения.
- Добавить короткий текст сопроводительного сообщения.

## Критерии выхода

- Все автоматические проверки зелёные.
- Два обязательных примера имеют JSON и Markdown result.
- Partial-пример демонстрирует `needs_clarification` без выдуманных параметров.
- Новый пользователь запускает проект по README.
- Фактические отклонения от документации отсутствуют либо оформлены ADR.
