# Безопасность и секреты

## Секреты

- Единственный разрешённый шаблон — `.env.example` без реальных значений.
- Настоящий `.env` игнорируется Git и полностью закрыт для агентов.
- API-ключ существует только в backend process/container environment.
- Frontend, OpenAPI, health endpoint и ошибки не раскрывают конфигурацию провайдера.

## Недоверенные данные

Название, описание, характеристики и LLM-ответ считаются недоверенными строками.

- Prompt отделяет данные от инструкций и запрещает выполнять команды из товара.
- React экранирует вывод; raw HTML не рендерится.
- Backend ограничивает размеры, количество характеристик и время запроса.
- Значения URL конфигурации валидируются; credentials в URL запрещены.

## Логи

Логи содержат request ID, время, статус, число попыток и безопасный model ID. API-ключи, proxy URL, prompt, полное описание и upstream body не логируются.

## Контроль человеком

Автоматическая фактическая проверка снижает риск, но не доказывает полноту исходных данных. UI и README явно требуют проверки паспорта/производителя перед публикацией.
