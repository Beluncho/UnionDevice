# Короткое сопроводительное сообщение

Реализован MVP AI-помощника для подготовки товарных карточек КИП: FastAPI API, React UI, OpenAI-compatible подключение с custom base URL/proxy и Docker Compose. Сервис формирует SEO-заголовок, описание, характеристики, поисковые запросы и commercial-блок, проверяет структуру ответа и не позволяет модели изменять значения характеристик.

Для демонстрации подготовлены два полных товара из YML-фида и отдельный partial-сценарий, показывающий обработку недостаточных данных. Получение исходных товаров вынесено в независимый one-shot `catalog-importer`, который не входит в runtime API.

Основная сложность — баланс между полезным маркетинговым текстом и запретом на выдуманные технические значения. Решение: provider abstraction, строгий prompt, детерминированные значения `specs`, grounding-validator и одна корректирующая попытка.
