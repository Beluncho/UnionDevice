# Результаты live smoke

После запуска приложения с пользовательским `.env` выполните из корня проекта:

```powershell
.venv\Scripts\python.exe tools\smoke_api.py
```

Команда отправит два полных и один partial fixture в API и сохранит ответы в этой папке. Скрипт не читает `.env` и не принимает API-ключ: ключ существует только в окружении запущенного backend.

Перед публикацией результатов вручную проверьте технические значения и длину SEO-описаний.
